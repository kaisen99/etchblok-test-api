The `BookmarkRepository` serves as the central data access layer for the application. It provides a clean, dictionary-backed interface for persisting bookmarks, tags, and collections. While currently implemented as an in-memory store, its design allows the rest of the application to remain agnostic of the underlying storage mechanism.

In this tutorial, you will learn how to initialize the repository and perform standard CRUD (Create, Read, Update, Delete) operations on your data.

### Prerequisites

To follow this tutorial, you need to have the core models and the repository available in your environment:
- `Bookmark` and `BookmarkStatus` from `app.models.bookmark`
- `Tag` and `TagColor` from `app.models.tag`
- `Collection` from `app.models.collection`
- `BookmarkRepository` from `app.db.repository`

### Step 1: Initialize the Repository

First, create an instance of the `BookmarkRepository`. In a production application, this is typically managed as a singleton within a service layer, but for this tutorial, we will instantiate it directly.

```python
from app.db.repository import BookmarkRepository

# Initialize the in-memory store
repo = BookmarkRepository()
```

The repository initializes three internal dictionaries to track `_bookmarks`, `_tags`, and `_collections`. Because this is in-memory, all data will be lost when the Python process terminates.

### Step 2: Create and Save a Bookmark

To persist data, you first need to create a model instance. The `Bookmark` class requires at least a `url` and a `title`.

```python
from app.models.bookmark import Bookmark

# Create a new bookmark instance
new_bookmark = Bookmark(
    url="https://github.com/features/actions",
    title="GitHub Actions",
    description="Automation for your workflow"
)

# Persist it to the repository
repo.save_bookmark(new_bookmark)

print(f"Saved bookmark with ID: {new_bookmark.id}")
```

The `save_bookmark` method handles both inserts and updates. If a bookmark with the same `id` already exists in the repository, it will be overwritten with the new instance. Note that the `id` is automatically generated by the `Bookmark` model if not provided.

### Step 3: Retrieve and Update Data

You can retrieve a specific bookmark using its unique ID. Once retrieved, you can modify its attributes and save it back to the repository to persist the changes.

```python
# Retrieve the bookmark by ID
bookmark = repo.get_bookmark(new_bookmark.id)

if bookmark:
    # Update an attribute
    bookmark.title = "GitHub Actions Documentation"
    
    # Use model methods to change state
    bookmark.archive()
    
    # Persist the changes
    repo.save_bookmark(bookmark)
    
    print(f"Updated status: {bookmark.status.value}")
```

The `get_bookmark` method returns `None` if the ID is not found. When you call `archive()`, the model updates its internal `status` to `BookmarkStatus.ARCHIVED` and refreshes its `updated_at` timestamp.

### Step 4: Query and Paginate Results

The `list_bookmarks` method allows you to retrieve slices of data. It supports 1-based pagination and filtering by status.

```python
# List the first page of archived bookmarks
items, total = repo.list_bookmarks(page=1, per_page=10, status="archived")

print(f"Found {total} archived bookmarks.")
for item in items:
    print(f"- {item.title} ({item.url})")
```

**Note:** The `status` parameter expects a string matching a `BookmarkStatus` value (e.g., "active", "archived", "trashed"). If an invalid status string is provided, the repository silently ignores the filter and returns all items.

### Step 5: Organize with Tags and Collections

The repository also manages `Tag` and `Collection` entities. You can associate tags with bookmarks by adding the tag's ID to the bookmark's `tags` list, or group bookmarks into collections.

```python
from app.models.tag import Tag, TagColor
from app.models.collection import Collection

# 1. Create and save a tag
dev_tag = Tag(name="Development", color=TagColor.BLUE)
repo.save_tag(dev_tag)

# 2. Associate the tag with our bookmark
bookmark = repo.get_bookmark(new_bookmark.id)
if bookmark:
    bookmark.add_tag(dev_tag.id)
    repo.save_bookmark(bookmark)

# 3. Create a collection and add the bookmark
reading_list = Collection(name="Work Reading")
reading_list.add_bookmark(new_bookmark.id)
repo.save_collection(reading_list)

# 4. Query bookmarks by tag
tagged_items = repo.get_bookmarks_with_tag(dev_tag.id)
print(f"Bookmarks tagged '{dev_tag.name}': {len(tagged_items)}")
```

The `get_bookmarks_with_tag` method performs a linear search through the in-memory store to find all bookmarks containing the specified `tag_id`.

### Complete Example

Here is the complete flow from initialization to cleanup:

```python
from app.db.repository import BookmarkRepository
from app.models.bookmark import Bookmark
from app.models.tag import Tag

# Setup
repo = BookmarkRepository()

# Create Data
tag = Tag(name="Reading List")
repo.save_tag(tag)

bm = Bookmark(url="https://example.com", title="Example Site")
bm.add_tag(tag.id)
repo.save_bookmark(bm)

# Query Data
results, count = repo.list_bookmarks(page=1, per_page=5)
print(f"Total bookmarks: {count}")

# Cleanup (Hard delete)
success = repo.delete_bookmark(bm.id)
if success:
    print("Bookmark deleted successfully.")

# Verify counts using internal helper
counts = repo._count_all()
print(f"Current counts: {counts}")
```

### Next Steps

Now that you understand how to use the `BookmarkRepository` directly, you can explore how it integrates with other parts of the system:

- **BookmarkService**: In a real application, you should use the `BookmarkService` (found in `app.services.bookmark_service`). It acts as a facade over the repository, adding validation, caching via `LRUCache`, and automatic indexing.
- **SearchIndex**: The `SearchIndex` (found in `app.services.search_service`) takes a `BookmarkRepository` instance in its constructor to build an inverted index for full-text search.

```python
from app.services.search_service import SearchIndex

# The SearchIndex requires a repository to function
search_index = SearchIndex(repo)
search_results = search_index.search("Example")
```
