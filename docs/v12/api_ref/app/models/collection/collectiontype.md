# CollectionType

The kind of collection.

## Attributes

| Attribute | Type | Description |
|----------|------|-------------|
| **MANUAL** | `string` = manual | Represents a collection where items are added and removed by the user manually. |
| **SMART** | `string` = smart | Represents a collection where items are automatically included based on predefined rules or filters. |
