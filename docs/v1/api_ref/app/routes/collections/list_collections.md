# GET /api/collections/

List all collections with their bookmark counts.

Retrieves a comprehensive list of all existing bookmark collections, including their associated metadata and bookmark counts.

## Endpoint

```
GET /api/collections/
```

## Response

| Status | Description |
|--------|-------------|
| **200** | Successfully retrieved the list of collections. Returns `application/json`. |
